## 👨‍💻 About Me

I'm **Md Abu Sayeed Riday**, a web developer who enjoys turning everyday needs into useful digital tools. My projects span hotel Lost & Found management, local service directories, e-commerce, and interactive React applications.

- 🏨 **Hospitality:** Building tools for item records, guest claims, and hotel staff workflows.
- 🌍 **Community:** Developing Comilla City to make local services and information easier to find.
- ⚙️ **Full stack:** Working with React, TypeScript, Node.js, Express, and MongoDB.
- 🎯 **Approach:** Clear interfaces, organized workflows, and features that help people get things done.
